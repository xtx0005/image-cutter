# 🖼️ 智能产品图批量切割器 (Image Grid Slicer)

一个为产品摄影/市场物料打造的**纯前端**图片切割工具。无需安装任何环境，仅需一个 HTML 文件即可在浏览器运行。

## ✨ 核心特性

- **🚀 极简运行**：纯前端单文件，无需配置 Python/Node.js 环境。
- **📦 批量处理**：支持一次性上传多张图片，直接进行 4 等分切割。
- **🧠 智能同步逻辑**：
  - **全局主控**：默认所有图片共享“图 1”的切割比例，一拖全动。
  - **独立微调**：点击任意图片并拖动滑块，即可打破同步，为其单独设定中心点。
  - **一键归队**：支持一键重置单图为跟随“图 1”设置。
- **🔍 实时预览**：带十字缝隙的实时视觉预览，确保完美避开主体文字。
- **🗂️ 分类打包下载**：多图状态下，一键生成 `.zip` 压缩包，自动按“原图名”建立文件夹，分别存放其四张切图。
- **💎 高清无损**：基于 Canvas 原生像素裁剪，输出 100% 原始分辨率的 PNG。

## 🛠️ 如何使用

1. 将代码保存为 `index.html`（或直接下载本仓库文件）。
2. 双击用 Chrome/Edge/Safari 浏览器打开。
3. 拖入或选择你的图片，滑动微调后直接下载！

## 💻 技术栈
- HTML5 / CSS3 / Vanilla JavaScript
- [JSZip](https://stuk.github.io/jszip/) (用于前端打包 ZIP)
